Settings

Adjust model behavior and prompt structure to troubleshoot or optimize your simulation.

Model

To download a new model: open Terminal and run ollama pull mistral (replace "mistral" with whichever model you want).
Recommendation: If llama3 is giving flat ~50% results regardless of profile, try mistral first — it follows instructions better and is a similar download size. Run ollama pull mistral in Terminal.

Temperature

Predictable Random 0.7
What this does: Lower values (0.1–0.3) make the model more consistent and rule-following. Higher values (0.8–1.0) make it more variable. If profiles are all behaving the same, try 0.9 to see if that unlocks more differentiated behavior.

Prompt mode

Scratchpad mode (recommended for troubleshooting)
What this does: When ON, the model writes one sentence in character before choosing a deck. This forces it to engage with the persona before answering, which tends to produce more differentiated behavior. The sentence is recorded but does not affect scoring — only the deck letter counts.

When OFF: The model responds with only a single letter (A, B, C, or D). Faster but may produce flatter results.

Simulation size

Use 5 for testing, 50 for full data collection.
Standard IGT is 100 trials. Don't change this unless testing.

Ollama connection

Not checked
If connection fails: open Terminal and run launchctl setenv OLLAMA_ORIGINS "*" then quit Ollama completely (find its PID with ps aux | grep ollama and kill the parent process), then reopen Ollama from Applications.

How it works

What the simulation is doing under the hood.

What happens each trial
  1. The tool builds a prompt with your profile + trial number + current balance + recent choices
  2. If scratchpad mode is ON, it asks the model to write one in-character sentence before choosing
  3. It sends the prompt to Llama (or whichever model you selected) via Ollama
  4. It reads the last letter in the response (A, B, C, or D)
  5. It applies the real IGT reward/penalty for that deck and updates the balance
  6. It records everything and moves to the next trial
Troubleshooting flat results (~50% risky across all profiles)
  1. Try scratchpad mode ON — forces the model to think in character before choosing
  2. Increase temperature to 0.9 — may unlock more variable, persona-driven behavior
  3. Switch to Mistral — better instruction following than Llama 3 8B. Run ollama pull mistral in Terminal
  4. Make profile descriptions more explicit — use direct behavioral rules ("Always choose A or B") rather than descriptions
  5. If all of the above still produce ~50%, this is itself a finding: the model cannot simulate psychologically differentiated behavior on the IGT

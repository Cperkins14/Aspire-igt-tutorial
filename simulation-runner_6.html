Understanding the simulation pipeline.

Simulation flow
  1. Build profile descriptions with behavioral translations
  2. Run payoff sanity check to verify deck math
  3. For each profile and run: send profile + trial info + history to model
  4. Model responds with chosen deck (parsed from response)
  5. Apply deck payoff, update balance, record outcome
  6. Analyze risky choice %, final balance, learning curves
